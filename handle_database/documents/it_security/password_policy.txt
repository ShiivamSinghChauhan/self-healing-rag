HelioVolt — Password & Authentication Policy
Document ID: HV-SEC-002 | Version 2.4 | Effective: Nov 1, 2025 | Owner: James Park (CISO)

1. SCOPE
Applies to all 482 employees, contractors, and interns with access to heliovolt.fake systems.

2. PASSWORD RULES
- Minimum length: 14 characters.
- Must include 3 of 4: uppercase, lowercase, digit, special character (!@#$%^&*).
- No reuse of last 12 passwords. No dictionary words or company name "heliovolt".
- Rotation: every 90 days for standard users, every 60 days for admins and finance.
- Lockout: 5 failed attempts = 15-minute lockout + alert to it-help@heliovolt.fake.
- Password manager: 1Password Business is mandatory. Vault name: HV-Employee. Sharing via 1Password only, never Slack or email.

3. MULTI-FACTOR AUTHENTICATION
- Okta Verify required for all SSO apps. SMS codes are NOT allowed.
- Hardware key (YubiKey 5C) required for: AWS console, GitHub Enterprise admin, VPN admin, finance systems.
- New device enrollment must be approved in Okta within 24 hours.

4. SERVICE ACCOUNTS & API KEYS
- API keys rotate every 90 days. Production keys stored in AWS Secrets Manager under hv-prod/*, never in code.
- Default pattern for internal test accounts: test+<team>@heliovolt.fake.

5. EXCEPTIONS
Request exception via Jira ticket SEC-EXEMPT with CISO approval. Max exception duration 30 days.

6. CONTACT
Questions: security@heliovolt.fake | Slack #security | IT Helpdesk ext 4357.
